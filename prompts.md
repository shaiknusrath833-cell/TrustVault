# AI Prompts Used – TrustVault

The following prompts describe the AI assistance used during the development of TrustVault.

## 1. Project Planning
Help me plan a secure document management system using Python Flask and SQLite.

## 2. User Authentication
Help me implement user registration, login, logout, and secure password hashing using Flask.

## 3. Document Management
Help me implement secure document uploads, file validation, document ownership, and document viewing.

## 4. Document Sharing
Help me implement document sharing with read and edit permissions, including permission revocation.

## 5. Admin Dashboard
Help me create an admin dashboard that displays registered users and document activity logs.

## 6. Security Review
Review my Flask application for security issues involving authentication, file uploads, permissions, sessions, and database access.

## 7. Testing
Help me test registration, login, document uploads, sharing permissions, revocation, and audit logging.

## 8. Documentation
Help me prepare project documentation and deployment instructions for TrustVault.
