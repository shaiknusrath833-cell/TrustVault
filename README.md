# TrustVault

TrustVault is a secure document management web application built using Python Flask, SQLite, HTML, and CSS.

## Features

- User registration and login
- Secure password hashing
- Document upload and storage
- File extension validation
- Document ownership and access permissions
- Secure document viewing
- Document sharing with read and edit permissions
- Permission revocation
- Admin dashboard
- Activity audit logs

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Running Locally

1. Install the required packages:

   `pip install -r requirements.txt`

2. Set the `TRUSTVAULT_SECRET_KEY` environment variable.

3. Run the application:

   `python app.py`

4. Open `http://127.0.0.1:5000` in your browser.

## Security

Do not publish your secret key, database, uploaded documents, or virtual environment.
